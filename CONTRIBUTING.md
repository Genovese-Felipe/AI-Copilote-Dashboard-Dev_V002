# Contributing

We welcome contributions to this project. Please follow these guidelines to ensure a smooth development process.

## Branch Protection

The `main` branch of this repository is protected with the following rules:

*   **Force pushes are disabled.** All changes must be made through a pull request.
*   **Deletions are disabled.** The `main` branch cannot be deleted.
*   **Status checks must pass before merging.** This ensures that all changes are tested and meet our quality standards.

## Pull Request Process

1.  Fork the repository and create your branch from `main`.
2.  Make your changes and commit them with a descriptive commit message.
3.  Ensure that your code adheres to the project's coding standards.
4.  Push your changes to your fork and submit a pull request to the `main` branch.
5.  Your pull request will be reviewed, and once it's approved and passes all status checks, it will be merged.
